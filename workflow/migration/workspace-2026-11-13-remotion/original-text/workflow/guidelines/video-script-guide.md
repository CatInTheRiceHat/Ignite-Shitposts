# Ignite video script guide

Use this to write short educational videos for Ignite. Start with the [guidelines index](README.md) for shared defaults and renderer choices. Pair each narration beat with a shot in [shot-integration-and-sol.md](shot-integration-and-sol.md). Use [video-style-guide.md](video-style-guide.md) for pacing and visual review.

## Write one answer viewers can see

1. **Hook.** Start in the first second with a question about something visible. Give the viewer an object, motion, or small mystery to track.
2. **Setup.** Show what changes. Give just enough context to make the reveal understandable.
3. **Reveal.** Time the answer to the close-up, movement, or before-and-after that proves the point. Explain the mechanism in plain English.
4. **Payoff.** End with the idea the viewer can take away. Sol can demonstrate it or react to it when that adds something to the ending.

Write for a curious middle or high school student. Use warm, energetic sentences that sound natural read aloud. Favor concrete verbs and one thought per line. Introduce a technical term after the viewer has seen what it means. Use a small, specific joke if it helps the explanation land. Flag greetings before the hook, filler, exaggerated clickbait, and lines that repeat a clear visual without adding meaning.

## Narration and timing

- Use the existing MoGoFun/TikTok voice **Cub (Female)** as the off-screen narrator unless the episode brief specifies a different voice. Sol communicates through body motion and interaction with the scene.
- New shorts default to **30 seconds**. Preserve intentional episode overrides: the calculus pilot is **15 seconds**, the Remotion zipper demo is **20 seconds**, and the Sol lantern test is **4 seconds**. Check the episode's own edit rather than resetting it to a shared duration.
- Write the draft before committing to shot timing. Time the final edit to the downloaded narration, leaving a brief pause where the viewer needs to see the answer. Keep narration, captions, and shot direction in separate fields.

| Beat | What to write | What to plan |
| --- | --- | --- |
| Hook | One question in the narrator’s voice | What appears on the first frame |
| Setup | The change the viewer should watch | One clear action or comparison |
| Reveal | A short explanation of why it happens | The exact detail to show as the line lands |
| Payoff | The takeaway in everyday words | The final image, or Sol’s purposeful action |

**Example hook, written for this guide:** “If your speed keeps changing, how far did you actually go?” Show Sol picking up speed and introduce the graph only when it helps answer the question. If using the existing calculus pilot, use its narration file and audio as the source for the actual words and timing.

## Review before generating shots

- [ ] The opening and ending address the same question.
- [ ] Each spoken line has something specific to show.
- [ ] The explanation is correct and the reveal lands with the matching line.
- [ ] The voiceover fits at a natural pace, with room to see the payoff.
